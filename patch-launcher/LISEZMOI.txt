Pour ton pote — Starblast Launcher + mods visuels
================================================

CE QU'IL DOIT DEJA AVOIR
  • Starblast Launcher installe (Starblast-Launcher-Setup-1_2_0.exe)
  • Node.js LTS : https://nodejs.org/  (une fois, gratuit)

CE QUE TU LUI ENVOIES
  Le zip patch-launcher (v1.1.12 ou plus recent) avec :
    - PATCH-LAUNCHER.bat      <- premiere installation
    - UPDATE-LAUNCHER.bat     <- mises a jour mods
    - VERIFY-MODS.bat         <- verifier bundle + patch Launcher
    - scripts/  inject/

================================================
 PREMIERE FOIS (dans l ordre)
================================================
  1. Installer Starblast Launcher + Node.js LTS
  2. Extraire le zip (ex. Bureau\patch-launcher\)
  3. FERMER completement Starblast Launcher (barre des taches aussi)
  4. Double-clic PATCH-LAUNCHER.bat  -> attendre "OK"
  5. Double-clic VERIFY-MODS.bat     -> "app.asar patche : OUI"
  6. Relancer Starblast Launcher

================================================
 OU SONT LES OPTIONS ? (souvent mal compris)
================================================

  Les nouvelles options ne sont PAS sur starblast.io dans Chrome.
  Il faut jouer VIA Starblast Launcher (Browser / Steam / ECP).

  1. Ouvre Starblast Launcher
  2. Ecran d accueil (welcome) -> bouton Parametres / Settings
     (icone engrenage ou menu en haut)
  3. Descends TOUT EN BAS de la fenetre Parametres
  4. Tu dois voir (apres Gem Color 1 / 2) :
       - Glow des gemmes (monde)
       - Neon barre gemmes
       - Couleur barre bouclier
       - Neon barre bouclier
       - Couleur barre energie
       - Neon barre energie
       - Leaderboard galaxie + neon pseudo
       - Couleur neon pseudo (leaderboard)

  Si tu ne les vois pas -> le patch n est pas actif (voir depannage).

================================================
 CE QUI CHANGE EN JEU (apres patch OK)
================================================
  • Gemmes blanches / glow (si options activees)
  • Barres HUD neon (bouclier, energie, gemmes)
  • TAB en partie : leaderboard avec galaxie sur TON pseudo
  • Ecran welcome : barre couleurs vaisseau (noir, gris, teintes)

  Gem Color 1 / 2 (deja dans le Launcher) = teinte des gemmes en monde.

================================================
 VERIFIER QUE CA MARCHE (preuve, pas opinion)
================================================

  A) VERIFY-MODS.bat
     -> Version bundle local : 1.1.11
     -> app.asar patche : OUI

  B) En jeu, F12 (console) :
     window.__SB_DESKTOP_MODS_VERSION
     -> doit afficher "1.1.11"

     window.__SB_DESKTOP_LAUNCHER_PATCH
     -> doit afficher true

  Si false ou undefined -> tu n es pas dans le Launcher patche
  (navigateur normal, ou patch echoue).

================================================
 MISE A JOUR (sans retélécharger le zip entier)
================================================
  1. Fermer Starblast Launcher
  2. Double-clic UPDATE-LAUNCHER.bat
  3. Relancer le Launcher

================================================
 DEPANNAGE
================================================

  "PATCH-LAUNCHER a plante"
    -> Utilise le zip v1.1.12 ou plus recent
    -> Ou UPDATE-LAUNCHER.bat a la place

  "Je ne vois pas les options Parametres"
    -> VERIFY-MODS.bat : app.asar patche = OUI ?
    -> Tu joues bien via le Launcher, pas Chrome direct ?
    -> Parametres depuis l ecran d ACCUEIL du Launcher
    -> Scroll en bas de la fenetre Parametres

  "Les options sont la mais rien ne change en jeu"
    -> Coche les options (neon, glow, leaderboard)
    -> Change Gem Color 1
    -> Relance une PARTIE (pas seulement le menu)
    -> TAB pour le leaderboard neon

  Restaurer Launcher original :
    resources\app.asar.bak  ->  renommer en  app.asar
